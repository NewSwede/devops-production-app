Operational Notes

Static HTML reduces moving parts. Nginx serves the UI directly, while the backend only handles API traffic. That is a good fit when CPU credits and memory are limited.

The UI avoids polling by default. Requests are user-triggered, which is deliberate for a small always-on VM.

Traffic Pattern

Burst-friendly and cheap: minimal client code, low asset count, and no SPA hydration cost.

Ops Posture

Health, version, and user data are visible without opening backend docs or shelling into the VM.

Frontend Scope

Purpose-built landing page for a small service, not a heavy dashboard that would waste instance headroom.
